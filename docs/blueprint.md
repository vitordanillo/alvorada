# **App Name**: Alvorada Smart Market

## Core Features:

- Manage products: Efficient product management: allows to create and manage a list of available products with attributes such as name, description, images and current pricing. Products have categories such as 'food', 'cleaning supplies' etc.
- Point of Sale (POS): A Point of Sale (POS) system where sales orders can be registered for walk-in customers.
- Financial Reporting: Financial record keeping.
- Dashboard and Reports: Dashboard and reports of business operations.
- User Authentication: Allow user authentication using Firebase authentication. Implement user permission roles: Administrator, Manager, Operator, Stockist
- Automatic Restock Suggestions: Generate automatic restock suggestions based on an analysis of the business operation, acting as an inventory management tool for optimal stock levels.

## Style Guidelines:

- Primary color: Soft blue (#74A9EA) for a calm and trustworthy feel, drawing inspiration from Apple's design language but with a slight deviation to suit a minimarket.
- Background color: Very light gray (#F5F5F7), providing a clean and modern backdrop that mimics Apple's interface aesthetic.
- Accent color: Light yellow (#E8DA74) to highlight key actions and interactive elements, complementing the blue primary color while maintaining a minimalist style.
- Headline font: 'Poppins' (sans-serif) for a modern, geometric, and highly readable appearance, suitable for conveying important information quickly.
- Body font: 'Inter' (sans-serif) for body text to ensure high legibility and a clean, contemporary look that aligns with Apple's typography principles. Pairs well with Poppins.
- Simple, outlined icons with rounded corners, designed to complement the minimalist aesthetic and provide clear visual cues. The iconography should maintain consistency with the chosen color palette, utilizing shades of gray and blue, for key features like cart and products.
- Extensive use of white space (negative space) to create a clutter-free and visually appealing interface. Elements are strategically placed to ensure ease of use and quick access to key functions, with a focus on responsiveness across devices.
- Subtle animations and smooth transitions, such as fades and slides, to enhance user experience and provide feedback on interactions. These animations should be unobtrusive and contribute to a sense of polish and professionalism, with care taken for mobile.
